# 长夜：叙事与角色基线

## 当前可玩的故事

入口是 DigGameView：莫斯下井找光晶，奥托在井口牵着光线；白天将晶体配成镇民需要的灯，收入用于下一夜的爪子、背包和灯芯。八块记忆石揭开莫斯与莫斯托的关系，井底通过放下背包、挥手完成第一章。此文是后续开发基线，不代表后续章节已经实现。

## 世界的规则

灯塔城的主灯熄灭，居民靠小灯维持生活。光晶能制灯，但不是取之不尽的太阳。记忆石保留过去的动作，不是全知旁白；玩家看到的石头、镇民的猜测与真实经历可以不同。莫斯托抱走的珠子是莫斯最早珍惜的光，不把它直接等同于太阳，避免与旧版战斗剧情混用。

地面承担关系与日常，地下承担探索与记忆。越深意味着更难返回，也意味着越接近被遗忘的朋友。黑暗中有危险，但“影子”本身不等于邪恶。

## 三个角色

**Moss · 莫斯**：台灯下醒来的小石头，薄荷叶是辨识轮廓。她通过触摸理解事物，以“我的”表达喜欢，也因此让双手越来越满。她想把亮东西带回家，更深的需要是确认朋友不会走。成长通过玩家放下背包表达；不能只用对白宣布她学会分享。保留好奇、占有欲与直率的喜剧，不把她写成训话者。

**Otto · 奥托**：守灯人，慢、困、寡言，可靠性通过一直牵着线表达。他以为守护就是不让任何人离开灯下，因此自己的成长是允许莫斯走远，同时保证她能回来。第一章不要突然补一个宏大的身世；先用灯芯、绳结和归来时的回应建立可信关系。后续可玩能力围绕照明、定锚与安全路径，而非单纯高攻击。

**Mosto · 莫斯托**：曾经在墙上回应莫斯的影子。歪王冠是自封的身份，也是害怕被遗忘的伪装。他模仿“都是我的”，抱走珠子是在重复莫斯的行为。他要的是被回头看见，不是金币。井底他仍会护住珠子，先看到莫斯空手挥手，才愿意借出一半。和解后保留淘气与边界，不能立即变成服从的宠物。后续能力围绕穿影、取远物与归还。

## 第一章的八个证据

1. 醒来：台灯、小石头。
2. 回应：挥手与影子，建立第一次陪伴。
3. 积攒：搬东西，朋友的手仍举着。
4. 背身：珠子与歪王冠，彼此模仿。
5. 忽略：藏品增多，影子长大。
6. 分离：影子拿走珠子，逃入黑暗。
7. 寻找：放下东西，空手走进暗处。
8. 重逢：看见发抖的小魔王，先挥手。

镇民回应以已发现的石头 ID 为条件。乱序找到不应凭数量透露未发现的事实；同夜找到多块要逐段读完。只在最后一句结束后写入已读标记，中断后可以重读。旧存档保留原有已读标记。

## 灯铺与镇民的持续变化

交付一盏灯后保存收灯人、灯色、交付日与累计次数。晚间对应窗口持续亮起，灯火记录可回看居民的回应：汉克看清绳结、琳恩分拣零件、朵拉补布偶、邮差分信、面包师守面团、老船长重读海图。后续来访承认上次的灯仍亮着，这次是换光，而非每天忘记玩家做过的事。回应目前属于叙事状态，不宣称发放了额外物品或改变地下物理。

交灯后的回应停留至玩家手动继续，避免显示到下一位顾客头上或一闪而过。旧存档仅有灯铺陈列颜色，不能据此推断收灯人；已有陈列保留，居民窗口从下一次实际交付开始记录。失败配色、资源不足、失效订单与重复调用均不改变交易或城镇状态。

## 重逢后的日常协作

第一章重逢后的协作已接入日常下井：“分一半”让莫斯托接走一部分物品，奥托在井口收好，莫斯腾出手继续探索。每夜只送一次；已送部分与身上背包分别保存，灯灭只折损未送部分。动作在后续夜晚解锁，结局会面中不能提前使用；中断的会面恢复后仍保留这一边界。

## 后续章节（待实现）

第二章“没有影子的街”：回到地面的莫斯托不能只在结尾出现。用三人协作修复一条街：奥托固定光源、莫斯移动实物、莫斯托在投影中取物。完成后镇民的灯与通路持续改变。先做一张可往返的小地图和一个完整任务，不一次扩张整座城。

第三章“灯照不到的地方”：一次过度保护造成的绕路让奥托面对自己的恐惧。玩家留下锚点、分开探索再汇合，失败仍回到最近安全灯，不损失已经读过的关系进展。

第四章“让太阳睡一觉”：长夜的原因必须通过前章可互动的证据成立。终局由三人的能力共同完成，给出可以继续生活的城镇状态；不靠临终独白或突然新增反派收束。

## 参考作品如何转成验收条件

- 《缩小帽》：能力改变同一地点的可达性；每个新能力先安全展示，再组合验证。
- 《星露谷物语》：镇民需要能改变日常；交灯以后应看见对应地方变亮，而不仅收入增加。
- Terraria：工具等级让地层与风险可读；受阻时明确指出所需工具，避免无反馈敲击。
- 《去月球》：用重复意象在后段改变早期理解；珠子、挥手、空手和绳结承担情绪，不照搬人物或情节。

每次交付应同时具备可操作目标、明确反馈、存档恢复和可观察的世界变化。Fable 5.2 的具体产品或版本尚未确认，不据名称编造技术结论。
